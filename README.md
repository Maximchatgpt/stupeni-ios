# Ступени для iPhone

Приложение-репетитор по алгебре для 7 класса — тот же аккаунт, чаты и тариф, что на сайте
[stupeni.maxsim.space](https://stupeni.maxsim.space). Интерфейс на SwiftUI с эффектом Liquid Glass (iOS 26;
на iOS 17–18 вместо стекла — обычное размытие).

## Где взять приложение

Каждый коммит в `main` автоматически собирается на Mac от GitHub (вкладка **Actions**).
Готовый файл всегда лежит здесь: **Releases → latest → `Stupeni.ipa`**.

## Установка на iPhone бесплатно (Windows + SideStore)

Нужно один раз на каждый iPhone. Платный аккаунт разработчика не нужен — подойдёт обычный Apple ID.

1. **Подготовка на компьютере с Windows**
   - Установите **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store).
   - Скачайте **AltServer для Windows** с сайта altstore.io и установите — он нужен только для первой установки SideStore.
2. **Установка SideStore на iPhone**
   - Подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру».
   - В iPhone включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** (телефон перезагрузится).
   - Скачайте `SideStore.ipa` с сайта sidestore.io и следуйте их инструкции «Install» — войдите своим Apple ID.
   - На iPhone: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → «Доверять».
3. **Установка «Ступеней»**
   - На iPhone откройте в Safari страницу Releases этого репозитория и скачайте `Stupeni.ipa` (сохранится в «Файлы»).
   - Откройте SideStore → вкладка **My Apps** → **+** → выберите `Stupeni.ipa`.
4. **Раз в 7 дней** откройте SideStore и нажмите **Refresh All** (или включите фоновое обновление).
   Без этого бесплатная подпись истекает, и приложение перестаёт открываться (данные не пропадают — они на сервере).

Ограничение бесплатного Apple ID: не больше 3 таких приложений на одном iPhone (SideStore считается одним из них).

## Обновление

После нового коммита дождитесь зелёной галочки в Actions, скачайте свежий `Stupeni.ipa` из Releases
и установите его в SideStore поверх старого.

## Что умеет первая версия

- Вход по коду из письма (можно вставить и ссылку из письма — код возьмётся из неё).
- Режимы «Репетитор» и «Расширенный ИИ» (Plus и Pro), выбор модели с иконками и описаниями.
- Чаты с формулами и графиками, история чатов, профиль с остатком запросов.

Дальше: загрузка фото и файлов, голосовой ввод.

## Устройство проекта

- `Stupeni/` — код приложения (SwiftUI). Ключей нейросетей в приложении нет: оно ходит только в API сайта.
- `project.yml` — описание проекта для XcodeGen (сам `.xcodeproj` создаётся при сборке).
- `scripts/make_icon.swift` — рисует иконку приложения; `icons/*.b64` — иконки моделей в текстовом виде.
- `.github/workflows/build.yml` — сборка `.ipa` без подписи; подписывает её SideStore на телефоне.
